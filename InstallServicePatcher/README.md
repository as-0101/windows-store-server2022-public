Имеются результаты испытаний на трёх ревизиях компонента InstallService: 20348.3692, 20348.5756 и 20348.5866. Универсальная совместимость не подтверждена. Изменение системной DLL нарушает её оригинальную цифровую подпись. Не отключайте защиту Windows; используйте изолированную VM и резервные копии.
