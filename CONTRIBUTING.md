# Как помочь проекту / Contributing

Спасибо за интерес! Этот публичный репозиторий посвящён **дистрибутиву, документации и воспроизводимым отчётам** для Windows Server 2022 x64. Полный внутренний журнал исследований находится отдельно и не предназначен для публичной публикации.

## Перед отправкой

1. Изучите [README](README.md), [FAQ](docs/FAQ.md) и [диагностику](docs/TROUBLESHOOTING.md).
2. Проверьте [открытые Issues](https://github.com/as-0101/windows-store-server2022-public/issues) на дубликаты.
3. Опишите один воспроизводимый дефект в одном Issue с версией Windows, версией DLL, этапом сбоя и точным кодом ошибки.
4. Публикуйте только очищенные от персональной информации логи и скриншоты.

## Pull requests

Предпочтительны улучшения документации, точные исправления воспроизведения, безопасная диагностика и проверки упаковки/хешей. Для изменений кода указывайте, что проверялось, что не проверялось, и способ отката. Никаких претензий на поддержку новых сборок без отдельного воспроизводимого теста.

**Не загружайте** в PR проприетарные системные DLL, приватные ключи, данные лицензий, токены, пользовательские логи и материалы из закрытых хранилищ. Не предлагайте отключение Windows Code Integrity, WFP или проверок лицензирования.
